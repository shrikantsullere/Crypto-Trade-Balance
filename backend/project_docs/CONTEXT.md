# Admin Panel Context

Admin Panel is the control system of Trade Balance platform.

## Purpose
- Manage users
- Control earnings & payouts
- Maintain genealogy structure
- Handle support system

## Modules
- Users Management
- Referral & Genealogy
- Earnings & Commissions
- Downloads Manager
- Support Manager

## Core Responsibility
Ensure system integrity, financial accuracy, and user trust.





# User Dashboard Context

## Overview
User Dashboard is the primary interface where users interact with the Trade Balance platform. It provides access to earnings, referrals, genealogy, downloads, and support.

## Core Purpose
- Show user performance
- Enable network growth
- Provide earning tools
- Offer support and resources

## Modules
- Dashboard (stats + activity)
- My Network (genealogy tree)
- Referral (invite system)
- Calculator (earning estimator)
- Downloads (documents)
- Chat (support system)

## User Goal
Earn money by growing network and understanding system.
